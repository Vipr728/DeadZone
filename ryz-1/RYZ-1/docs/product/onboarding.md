# Onboarding

1. Install the embedded or registry package.
2. Open `Tools > Ryzi`.
3. Use Setup and Diagnostics to confirm package/provider availability.
4. Click `Scan Current Scene`; review evidence and unresolved issues.
5. Enter Play Mode if the selected provider requires isolated physics, then run calibration.
6. Run the baseline test, inspect local evidence, enable the Scene overlay, and replay a selected result.
7. Run the three-value counterfactual; candidate values are temporary and originals are restored.

Opening the window and scanning make no scene or settings changes. Authentication is not required. Usage
telemetry is disabled and no upload operation exists in this slice.
